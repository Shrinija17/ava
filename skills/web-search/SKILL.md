# Web Search Skill

When the user asks you to search for something, look something up, or needs current information:

1. Use the `web_search` tool with a clear, concise query
2. Summarize the top results conversationally
3. If the user wants more detail, offer to fetch a specific URL with `web_fetch`

Keep search-based answers brief and cite where the info came from.
